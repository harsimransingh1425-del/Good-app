## How to use on your Android phone as an App / APK:

### Option A: Install instantly as a Native Web App (Direct & Free, No APK compiler needed)
1. Open `index.html` in Chrome on your Android phone.
2. Tap the three dots (⋮) in the top right corner.
3. Tap **"Install app"** or **"Add to Home screen"**.
4. Aura will appear on your phone screen with its own icon, fullscreen display, and offline persistence.

### Option B: Convert directly into a signed `.apk` file
You can package this folder into a native Android APK in under 2 minutes using either of these free automated builders:
1. **PWABuilder (Recommended by Microsoft & Google):**
   - Host `index.html` and `manifest.json` on GitHub Pages, Vercel, or Netlify (free 1-click).
   - Paste your URL into [PWABuilder.com](https://www.pwabuilder.com).
   - Click **Generate Android APK** -> Download your signed APK and install it directly on your phone.
2. **Web2APK / Website 2 APK Builder:**
   - Open Website 2 APK Builder (or Capacitor / Cordova).
   - Point to this local directory (`index.html`).
   - Click "Generate APK" to output the `.apk` package.
